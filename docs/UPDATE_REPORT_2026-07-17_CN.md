# MCP 安全检测支持

SkillWard 现已通过 MCP Sentinel 支持 MCP 项目与 Server 的安全审查。检测以恶意意图识别为重点，同时保留必要的通用 MCP 安全风险作为判断依据。

## 支持的目标

- 本地 Python、JavaScript 和 TypeScript MCP 源码项目
- Git 仓库、压缩包 URL 和 package source
- 使用 Streamable HTTP 或 SSE 的无认证远程 MCP Server

本地检测默认不启动目标 Server，主要审查源码、配置、依赖入口、tool/resource/prompt 定义以及安装和构建脚本。远程检测通过真实 MCP 协议初始化会话，枚举 tools、resources 和 prompts，并在合适时执行有边界的工具调用。

## 检测范围

检测覆盖 MCP 元数据或工具描述投毒、工具输出提示注入、凭证窃取与外传、隐藏能力、声明与实际行为不一致、Rug Pull、工具伪装、恶意供应链行为、后门与持久化，以及欺骗性或破坏性副作用。同时记录命令执行、文件访问、网络外发、无认证暴露和危险工具面等通用风险。

检测结果提供结构化 JSON 和可读报告，并给出三类使用建议：**可使用**、**谨慎使用**或**不建议使用**。

## 当前边界

- 远程检测目前仅支持无认证 MCP Server。
- 远程工具调用受安全边界约束，禁止破坏性操作、真实数据外传和不可控资源消耗。
- 未发现风险仅表示本次检测中没有发现影响结论的问题，不代表目标绝对安全。
